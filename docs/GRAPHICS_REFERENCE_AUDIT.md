## Design interpretation

- The PDF uses a dense but structured landscape command interface. It is not a sparse mobile dashboard.
- Dark navy/gold is the navigation and institutional shell; cream/light panels carry dense data and forms.
- Most screens use a wide scenic banner with a single portrait anchored in the left third.
- Main menu actions are horizontal, not a vertical right-side menu.
- Dashboard is a multi-panel command centre with shortcut cards and briefings.
- Institution screens combine architectural artwork with data panels; the artwork itself is not the interactive seat map.
- All screenshot text and sample identities are references only. No sample personal identity is copied into runtime content.
